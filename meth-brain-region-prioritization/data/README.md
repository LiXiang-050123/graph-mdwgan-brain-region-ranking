# Data

`brain_region_cfos.xlsx` is the processed 24-animal by 18-region c-Fos dataset used in the manuscript. The spreadsheet is stored in the original region-by-animal layout expected by the analysis scripts.

The matrix contains 11 saline-treated and 13 methamphetamine-treated rats pooled across the two behavioral paradigms available in the source dataset. See the manuscript for the original study citation and experimental details.
